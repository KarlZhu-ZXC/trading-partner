# v0.2.0 — Phase 3 facts and judgment controls

Released on 2026-07-26.

## Breaking

- 最小生产安装不再强制携带 Moomoo、Schwab、Matplotlib 与 pypdf；按需安装
  `accounts-moomoo`、`accounts-schwab`、`chart`、`company-pdf`，或使用 `all` 完整 extra。
- 公共 MCP 工具面固定为 `compact_28`；旧工具名和 profile/config 开关均不保留 alias。
- `watchlist_get` 只读 durable state；唯一公共刷新入口是
  `external_state_sync(request={"operation":"watchlist"})`。
- compact instrument-only Deep Dive 不再隐藏创建 Draft；需要新 Case 时先显式调用
  `investment_case_manage(request={"operation":"create",...})`。

## Added

- `research_workflow_run(request={"operation":"peer_comparison",...})`：对调用方明确指定的
  1–5 家同市场 A 股/美股同行，串行收集并对齐年报/最新报告期、当前估值和可选 A 股经营
  指标；保留币种、期间、来源与缺失语义，不自动选同行、排名、评分或生成目标价。
- 候选确认/拒绝新增 Codex 聊天授权转交：用户在当前聊天中的明确决定使用
  `reviewed_by=user`、`submitted_via=codex_chat` 和有界 `authorization_note` 直接提交，
  无需独立审核 UI；审计记录区分用户决定、Codex 转交通道和 caller-asserted 身份保证。
- compact 28 使用 capability-scoped operation adapters 直接组装唯一 FastMCP，不再经过
  HandlerRegistry、旧工具名查找或第二次参数模型反射；公开输入 schema 会共享重复属性定义。
- selection/safety eval catalog 新增 9 个场景，覆盖此前遗漏的公共 operation 和 A 股/美股
  同行比较；89 个场景现在必须覆盖全部 28 个公共工具。
- 免费 CME 金属具体合约定义、官方参考 settlement/volume/OI、期限结构和连续映射。
- Yahoo active-contract quote/bars，禁止具体合约静默回退为 `*=F` 连续代理。
- Dukascopy XAUUSD/XAGUSD broker/SWFX quote/bars，以及独立 rolling copper CFD 身份。
- DCE 生猪官方 EOD 合约链与期限结构；访问限制使用 typed degradation。
- `market_data_get` 的 `futures_curve` 与 `spot_future_basis` operation。
- CME/OTC Monitor 与 Technical Engine 路由。
- `trading-partner-futures-sync` 显式定义/EOD statistics 同步命令和持久化 vintage。
- Phase 3D append-only Trade Plan identity/version/condition 持久化；复用既有 Candidate
  propose/confirm 生命周期；Codex 不得自主决定结果，但可转交用户的明确聊天授权。
- `portfolio_risk_get(request={"operation":"check","trade_plan_id":...})` 的 A 股/美股确定性
  Position Sizing 与 Risk Engine v2。
- Trade Plan 条件到 Monitoring v2 的显式编译，以及九类确定性事实比较和 typed
  `NOT_EVALUATED` 状态转换。

## Boundaries

- 默认链零数据订阅费、零 trial 依赖；CME/DCE 公开数据和 Yahoo/Dukascopy 均无 SLA。
- LBMA、LME Cash/3M、DCE 分钟行情、过期 CME 完整历史和 back-adjusted 数据未实现。
- 所有接口保持只读；没有 order、fill、position mutation 或 runtime LLM。

## Removed

- 删除旧 52 工具的运行时 profile、FastMCP registrar、public inventory、迁移映射 fixture
  和专属兼容测试；`compact_28` 成为唯一可启动的 MCP 工具面。
- 删除内部 HandlerRegistry、ToolRegistrar、52 个 `@server.tool` 收集点和独立
  `research_context` 适配文件；业务 operation 直接由 compact capability adapters 承接。
- 删除未进入公共 MCP 面、仅服务旧测试的 mock market snapshot service/router/provider/codec
  链及其重复测试；真实 ProviderRouter、Instrument Master 和 compact 28 工具面保持不变。
- 删除已退出路线图的 StockTwits 运行时 adapter、设置与 HTTP allowlist；保留历史 enum/数据库
  值兼容，不删除既有数据。
- 删除未被任何 Provider 消费的通用 `broker_api_*` 设置占位符；券商配置继续使用明确的
  Schwab/Moomoo provider-scoped 字段。

## Fixed

- 修复 schema 最小化后 discriminator mapping 仍指向改名前 `$defs` 的悬空引用；新增全工具
  local-ref 完整性守卫。重复属性 schema 共享后，28 个工具输入 schema 合计保持低于 40 KiB。
- Dukascopy 主链改为当前 `dukascopy-node` 使用的 keyless Jetta JSON 分桶接口；实现
  日/月/年历史桶、活动桶 `from` 查询、每批 10 请求与跨批 1 秒节流、不可变桶缓存，
  并严格解码 base-plus-delta 列式数据而不补造平 K 线。旧 `/2.0/` key API 仅作为
  可选兼容 fallback。网络错误继续只披露脱敏 operation 与 direct/proxy 路径。
- 新增 `PROVIDER_PROXY_URL`，统一承载 CME、DCE、Dukascopy 与 Polymarket 的可选
  HTTP(S) 代理；保留旧 Polymarket 变量作为兼容 fallback。系统健康组件明确改名为
  `*_configured`，避免把静态接线检查误读成 live connectivity。
- `DUKASCOPY_API_KEY` 从默认门槛降为 legacy fallback 可选项；keyless Jetta 可直接提供
  XAUUSD/XAGUSD 与 rolling copper CFD。报价明确标注为 BID/ASK 一分钟收盘代理，携带
  `data_delay_seconds`，不冒充 tick、LBMA/LME benchmark 或交易所成交量。
- Portfolio Review 默认只读 durable transactions，不再在 `refresh_accounts=false` 时隐式访问
  券商并持久化交易。
- Workflow receipt 与 research context live-tool hints 统一使用真实公共 MCP 工具名。
- A 股财务 Monitor 缺少 publication timestamp 时返回 typed `NOT_EVALUATED`，不再用报告期末
  伪造发布时间。
- ACTIVE Trade Plan 禁止关联 `INVALIDATED` 或 `ARCHIVED` Thesis。
