# v0.6.0 — Agent runtime and decision operations

Released on 2026-08-11.

## Highlights

- Added a disabled-by-default, provider-neutral Shared Agent Runtime for Console and
  Telegram. It reuses exact MCP operation contracts, durable conversations, bounded
  context, secret-safe receipts, serialized turns, and explicit pending-action gates.
- Added immutable Trade Retro preparation, deterministic transaction-discipline
  findings, human review revisions, history, CLI scheduling, safe Obsidian export,
  optional bounded Chinese narration, and a dedicated Console workspace.
- Added append-only Catalyst Agenda synchronization and outcome linking, daily
  mobile notifications, durable coverage receipts, and Console management.
- Added Judgment Scorecard S1 with deterministic Catalyst outcome calibration while
  preserving S0 history and intentionally avoiding an aggregate score.
- Added Schwab SGOV cash-sweep planning plus confirmation-gated live stock/ETF order
  preview, submit, status, and cancel boundaries. Unknown writes are never retried.
- Expanded the Console with Chat, Agenda, Retro, Scorecard, decision-inbox, Monitor,
  and research-continuity workflows.

## Market data and monitoring

- Canonical quote DTOs now keep Provider-specific fields behind adapters and expose
  stable `display_price`, `price_basis`, `session`, `previous_close`, and
  `previous_close_basis` semantics.
- US equity and ETF current quotes use timestamped pre-market, post-market, and
  supported Moomoo overnight observations when available; previous close always
  means the previous completed regular session close, never an arbitrary prior bar.
- Composite Monitor model timeout/fallback diagnostics are durable and produce one
  concise operational-degradation notice without hiding deterministic rule results.
- Bailian Qwen and DeepSeek fallback routing is provider-neutral and secret-safe.

## MCP contract

- The public `mcp_vnext_shadow` surface contains exactly 27 tools. Challenge Review,
  Catalyst Agenda, Judgment Scorecard, Trade Retro, and broker operations reuse
  existing grouped capabilities and exact internal operation validation.
- Validation-equivalent schema minimization now inlines only definitions that reduce
  bytes, compacts nullable forms after inlining, and minimizes output schemas.
  Aggregate input schema is 25,615 bytes; the complete tools/list wire representation
  is 35,601 bytes, with a 3,025-byte largest individual input schema.

## Reliability and safety

- Research Subject, Thesis, Trade Plan, Monitor, assumption, invalidation, open
  question, and linked-subject ownership/lifecycle invariants are revalidated before
  confirmation and never repaired through hidden cascades.
- Risk v2 accounts for supported open BUY-order exposure and reports incomplete or
  unknown order facts instead of treating them as zero.
- Migrations 0037–0046 add Trade Retro, reviews, Scorecards, Catalyst Agenda,
  broker-order receipts, and Shared Agent Runtime persistence.
- This release does not add autonomous confirmation, unattended trading, short
  selling, options/complex orders, replacement, or automatic retry of uncertain
  broker writes.
