# v0.5.0 — Research Subjects and intelligent monitoring

Released on 2026-08-09.

## Highlights

- Completed the user-facing migration from Investment Case to **Research Subject**
  while retaining legacy MCP wire names and opaque `case_` IDs for compatibility.
  Subject lifecycle is now exactly `DRAFT`, `ACTIVE`, and `ARCHIVED`.
- Added multi-Thesis structure with one live PRIMARY, sibling SUB drivers, and
  explicit COMPETITOR/BEAR alternatives. Parent/rival scope and lifecycle
  dependencies are enforced at proposal and confirmation.
- Added confirmed Instrument Selection for theme-first research. A Subject may
  maintain watching, shortlisted, selected, and rejected candidates before a final
  ETF or equity is chosen for a Trade Plan.
- Added optional composite Monitor judgments through Alibaba Cloud Model Studio
  `qwen3.8-max`, with DeepSeek retained as a configurable alternative. Deterministic
  features, evidence allowlists, session alignment, quantity caps, immutable
  receipts, Chinese explanations, and change-only invocation constrain model use.
- Added daily/weekly technical Monitor rules, recovery hysteresis, and explicit
  separation between a Trade Plan execution instrument and each condition's
  reference instrument.
- Added keyless weekend references for XAUUSD and light oil: Binance PAXG/USDC and
  Hyperliquid XYZ CL/USDC, with IG Weekend Gold as a final gold fallback. Retryable
  failures receive three bounded attempts and persist secret-safe Provider-stage
  diagnostics visible in the Console.
- Completed the loopback-only Console control room with Attention Queue, complete
  Research workspace, Monitor Run/event/observation diagnostics, operational
  receipts, Data Quality, Portfolio, and the 28-tool capability workbench.
- Simplified the local Console build from the unused Cloudflare/vinext Worker stack
  to native Next.js. This removed 158 transitive packages, restored native
  TypeScript build checking, and brought `npm audit` to zero known vulnerabilities.

## Contract and reliability

- The public MCP inventory remains exactly 28 tools and advances to
  `compact-v19`; input-schema wire size was reduced without weakening closed
  operation unions.
- Research Subject → Thesis → Trade Plan transitions now reject incoherent live
  state with non-retryable `RESEARCH_STATE_CONFLICT` and never hide conflicts by
  auto-activating or cascading entities.
- Research Subject titles and summaries describe the durable research object and
  scope; action language belongs to Thesis or Trade Plan.
- Telegram Outbox supports Monitor events, consolidated market-close runs, internal
  system notices, and explicitly authorized manual text without adding an MCP tool.
- Dukascopy OTC quotes expose `display_price` and `price_basis`; Yahoo extended-hours
  fallback preserves the correct observation-day previous-close baseline.
- Provider admission, Schwab/Moomoo account normalization, persistence ordering,
  and typed failure diagnostics received additional regression coverage.

## Documentation

- Consolidated completed implementation plans into the phase and capability guides.
- Moved QuantConnect Free into a current operator guide after exercising the manual
  prepare → web backtest → result-import path.
- Kept only genuinely unfinished work under `docs/plans/` and preserved historical
  release notes without rewriting their original schema versions.

## Safety boundary

This release does not add order placement, fills, paper trading, an automated
backtest runner, or autonomous confirmation. Optional Monitor model judgments have
no research-state, portfolio-state, or execution write port.
