# v0.5.1 — Portable MCP onboarding

Released on 2026-08-09.

## Highlights

- Added a pinned `uv tool install` path for the core package without cloning the
  repository.
- Added `trading-partner-init`, which creates an owner-only explicit runtime file,
  initializes or upgrades the local SQLite database idempotently, and prints stable
  MCP command/argument paths.
- Packaged the complete Alembic migration tree in the wheel and extended isolated
  wheel smoke coverage through real database initialization.
- Added tested setup recipes for Claude Desktop, Cursor, and generic stdio MCP hosts,
  plus a concise Chinese quick-start guide.

## Boundary

Initialization does not contact a market-data Provider or broker, does not require
credentials, and never overwrites an existing runtime configuration. Uninstalling
the executable deliberately preserves the user database.
