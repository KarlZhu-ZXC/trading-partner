# v0.9.0 — Moomoo notes and Codex conversations

Released on 2026-10-10.

## Moomoo notes and Codex conversations first

- Make Your Notes the default Console entry and place archive/state dashboards in
  a collapsed background workspace, retaining risk and operational exceptions.
- Add model-independent metadata and explicitly authorized, paginated note reads;
  preserve attribution, full/summary coverage, exact revisions and secret redaction.
- Add explicit Moomoo-only synchronization with no model or broker refresh.
- Allow user-confirmed Journal discussion records to link a FULL note revision
  without creating or maintaining a Research Subject. Formal judgment and order
  gates remain separate; exact recorded discussions may be folded in the note view.
- Extend the single MCP surface to v15 (nine entry tools, 24 capabilities,
  109 operations), retain old entry operations, and update Codex host guidance.
  Built-in Agent raw-note text remains blocked. No database migration is required.

## Upgrade and daily use

- Migration head remains `0073_research_evidence_links`; upgrading from v0.8.0
  requires no database migration. Rebuild/restart the source Console and reconnect
  MCP hosts to discover `mcp-vnext-shadow-v15`.
- Write notes in Moomoo, explicitly sync notes, then ask Codex to read and discuss
  selected notes. Only record a note-linked Journal conclusion when requested.
  Maintaining a Research Subject or producing a daily Decision is not required.
- Existing Moomoo note-source access must be configured and valid. This release
  does not add Moomoo UI automation, automatic private-content model use,
  autonomous confirmation, or broker refreshes.
- Automated checks use synthetic notes. Live private-note ingestion and measured
  human task-time improvement are not claimed as release acceptance results.
