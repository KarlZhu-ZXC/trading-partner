# v0.7.0 — Research review workspace and Copilot evidence

Released on 2026-09-16.

## Highlights

- Connected immutable Observations to reviewed Research Subject, Thesis, Trade Plan
  and Decision history. Changes Since Review, Quick Review, grouped Today Review
  and Weekly Review keep exact baselines, independent source coverage and recoverable
  drafts without implicit confirmations or refreshes.
- Added explicit Copilot Research and Counter-review modes with time/call budgets,
  current-turn field evidence, durable progress and usage receipts. Readable field
  displays retain identity, units, time and basis with expandable provenance.
  Bounded model notes, inline references and numbered explanations retain useful
  content; evidence-invalid critiques preserve the primary answer.
- Added an interactive KLineChart technical workspace, deterministic SMC overlays,
  reviewed chart-to-research draft handoff, SEC annual diluted-EPS/P/E scenario
  versions and Decision-pinned judgment calibration. Unsupported valuation methods
  and historical attribution remain explicit gaps.
- Extended Journal with Decision-linked broker activity, deterministic long-only
  Trade Cycles, native-currency performance, behavior review and exact timelines.
  Missing fees, corporate-action lots, cost basis and FX coverage are not estimated.
- Hardened runtime recovery, operational job leases, notifications, provider routing,
  local search, authenticated LAN access and complete Console reads. Optional
  Moomoo note enrichment retains immutable revisions, attribution and explicit
  private-content model authorization.

## MCP compatibility and upgrade

- The public `mcp_vnext_shadow` v12 surface now has nine entry tools over 24 business
  capabilities and 106 operations. Reconnect MCP clients after upgrade and use
  capability discovery for exact schemas. Removed entry names remain internal
  capability identities, not callable aliases.
- Migration head is `0072_external_note_review_drafts`. Back up the runtime database
  before upgrading, then explicitly run `trading-partner-init` to apply packaged
  migrations. Ordinary startup and reads do not migrate.
- Migrations `0069` and `0070` are forward-only repairs. Restore from a verified
  backup rather than attempting an empty downgrade.
- See the [upgrade guide](../guide/mcp-host-setup.md#upgrade-and-uninstall) and
  [current product specification](../product.md) for supported workflows.

## Execution and privacy boundaries

Research decisions remain explicitly reviewed and versioned; research authorization
never authorizes an order. Schwab stock/ETF writes retain their exact preview and
submit/cancel gates, and unknown submit outcomes are never automatically retried.
The installed SGOV-only cash-sweep scheduler is the sole dedicated unattended BUY
exception; it grants no general Agent/MCP execution authority.

Private notes, account data and credentials remain outside source, fixtures and
release artifacts. Korean-market expansion is excluded from future plans; existing
implemented support is retained.

## Acceptance and limitations

The source-only real-model acceptance harness uses fixed synthetic facts and an
in-memory runtime with no business or market access. All four scenarios have passed
with explicitly selected DeepSeek Flash `high` effort, with the resulting examples
manually reviewed. This is not proof of general semantic correctness or investment
effectiveness. The configured `max` default is unchanged and can exceed the default
180-second budget. Field verification does not verify a model's interpretation.

Trusted-LAN mode is authenticated HTTP, public/free data routes remain best effort,
and portfolio performance remains native-currency. See
[Known Issues](../operations/known-issues.md) for current operational constraints.
