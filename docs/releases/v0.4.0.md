# Trading Partner v0.4.0

Released: 2026-08-06

This release turns the compact-28 MCP and local Console into a more complete
research, portfolio, and monitoring control room while preserving the project's
read-only execution boundary.

## Portfolio and account intelligence

- Added durable account-activity coverage receipts and normalized transaction
  history, including Schwab 60-day paging and explicit Moomoo category/fee gaps.
- Added native-currency FIFO performance attribution with realized and unrealized
  P/L, dividends, interest, known fees, external cash flow, and traceable activity
  IDs. Incomplete history or reconciliation remains explicit.
- Added an owner-only Schwab Realized Gain/Loss CSV reconciliation CLI. It never
  contacts Schwab and writes only redacted, owner-only comparison artifacts.
- Expanded durable account snapshots to preserve environment, base currency,
  snapshot/fetch times, cash, buying power, net assets, margin used, open orders,
  and data-quality warnings.

## Local Console closure

- Added a Research master-detail workspace for every active or archived Investment
  Case, its Thesis, assumptions, invalidations, questions, Trade Plan, candidates,
  and linked Monitors.
- Added confirmed, idempotent Investment Case metadata updates without weakening
  Candidate → Confirm controls for Thesis and Trade Plan changes.
- Completed the Portfolio Hub with Holdings, Activity, Performance, Risk, and
  Watchlist tabs. Initial reads remain durable-only; upstream synchronization is
  always an explicit action.

## Monitoring and Telegram

- Made Dukascopy XAUUSD/XAGUSD interval schedules venue-aware, including weekend
  closure and daily maintenance windows. Closed venues no longer generate repeated
  synthetic `NOT_EVALUATED` runs.
- Added an explicitly enabled IG Weekend Gold/Apify fallback for current XAUUSD
  price rules. It is always labelled as a weekend CFD proxy, never spot or LBMA.
- Consolidated each A-share/US/KR post-market group into one Telegram summary,
  removing duplicate per-symbol plus group notifications.
- Mobile alerts now identify every changed rule by exact condition, threshold,
  meaning, severity, prior/current price, source, and transition state. Percentage
  changes use exactly two decimal places.
- Fixed interval anchoring and live-evaluation timing so Provider latency and fresh
  scrape timestamps do not create false missed cycles or stale/future-time errors.

## Provider resilience and data quality

- Replaced reject-only Provider counters with a bounded, cross-process admission
  scheduler. Queued admission, local wait timeout, and real upstream rate limiting
  now remain distinct typed outcomes.
- Added a durable-only Data Quality Center for account snapshot coverage, activity
  receipts, Monitor blind spots, and version-aware latest-run evidence.
- Persisted secret-safe Provider route receipts and exposed 24-hour failure,
  fallback, and cache aggregates. Payloads, fingerprints, exception text, and
  credentials are never persisted.

## Market and technical facts

- Added Dukascopy `LIGHT.CMD-USD` as `cfd:OTC:LIGHT_CMD_USD`, with `USOIL` as a
  lookup alias. It is explicitly an OTC rolling light-oil CFD, not WTI spot, NYMEX
  `CL`, a specific contract, or a continuous futures series.
- Technical snapshot/chart requests now use canonical `1d`/`1w` intervals while
  accepting common conversational aliases.
- Yahoo extended-hours recovery no longer combines a new pre/post-market price with
  stale regular-session range or volume fields.
- Fixed Risk v2 handling of legitimate negative cash in margin accounts.

## Public surface and engineering

- Kept the public MCP surface at exactly 28 tools and advanced it through
  `compact-v14`.
- Reduced schema duplication, modularized A-share domain/DTO validation, tightened
  composition boundaries, and upgraded GitHub JavaScript actions to Node 24-backed
  releases while continuing to test the Console on Node 22.
